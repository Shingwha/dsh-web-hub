# dsh-web-hub

[中文](README.md) | [English](README.en.md)

给 DeepSeek Harness 提供搜索与抓取工具：**一个开关表决定模型能看到什么**，来源只是工具的分组。

一家提供搜索、另一家提供抓取，甚至和内置的官方工具混用，都可以任意组合。

## 环境要求

- DeepSeek Harness `>= 0.2.2-rc.3`（带 Web GUI 的版本）
- 无需额外运行时；API Key 可选

## 安装

### 方式一：从 GitHub 安装（推荐）

1. 打开 DSH 左侧栏的 **Plugins**。
2. 点 **Add plugin**。
3. 输入下面这行，确认：

   ```
   github:Shingwha/dsh-web-hub
   ```

4. 等待安装完成（首次会拉取依赖，约几秒）。
5. **刷新一次页面**，让浏览器加载面板代码。

### 方式二：本地打包安装（开发用）

```sh
npm pack
```

把生成的 `dsh-web-hub-<版本>.tgz` 的**绝对路径**填进 Add plugin。

不要直接选插件目录：pnpm 会把目录装成 `link:`，`@deepseek-ai/*` 依赖解析会失败。

## 装好之后

- **什么都不变**：内置的 `web_search` / `web_fetch` 保持开启，插件不擅自接管
- 所有来源工具默认**关闭**，想用哪个就打开哪个

这样安装不会让你原有的搜索/抓取失效；需要更强的来源时再逐项打开。

## 配置

打开 **Plugins → dsh-web-hub**。面板按来源分组，顶部显示已启用工具数；每组先列出该来源的 API Key（需要时），再列出它提供的工具。每个工具右侧有一个开关：打开后模型在下一步即可调用，关闭后从工具列表移除，且不占 token。

密钥是可选项，操作顺序如下：

1. 点「获取 API Key」打开来源控制台，复制 Key。
2. 把 Key 粘贴到组内的 API Key 输入框，点「保存」；配置成功的来源会显示「已配置」标记。
3. 需要更换时直接保存新 Key；点「清除」移除本机凭据。

密钥只写入本机凭据库，配置文件里仅保存引用名；不需要密钥的来源在组标题旁显示「免 key」。

## 支持的来源

| 来源 | 搜索 | 抓取 | 免 key 可用 |
|---|---|---|---|
| **AnySearch** | ✅ | ✅ | ✅ 匿名，限额较低 |
| **Exa** | ✅ | ✅ | ✅ |
| **Tavily** | ✅ | ✅ | ✅ 有每日额度，用尽后需 key |
| **Firecrawl** | ✅ | ✅ | ✅ 匿名额度低 |
| **Parallel** | ✅ | ✅ | ✅ 深研需 key |

## 卸载

在 Plugins 里停用或移除 **dsh-web-hub**：

- 它挂载的工具全部消失
- 被关闭的内置网页工具自动恢复
- 不需要改其它配置

## 加一个来源

在 `src/adapters/` 里加一个文件，声明它自己的工具，再到 `src/adapters/index.js` 登记一行；核心与面板都不用改。详见 [docs/DETAIL.md](docs/DETAIL.md)。
