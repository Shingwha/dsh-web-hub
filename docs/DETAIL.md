# Web sources

把搜索与抓取能力做成**来源可切换、工具可开关**的一组模型工具。

## 它解决什么

DSH 内置的 `web_search` / `web_fetch` 只有一个固定形态，换后端就要改宿主编排；而不同搜索服务的参数、返回、配额策略差别很大。这个插件让**每个来源保留自己的工具契约**，模型看到的就是该来源真正提供的能力。

## 怎么用

1. 打开 **Plugins → 网页来源**
2. 选一个来源（当前只有 AnySearch）
3. 勾选需要的工具，例如 `anysearch_search` 与 `anysearch_extract`
4. 需要更高限额时填入 API Key；留空则匿名调用

保存后工具立即重建；被关掉的工具从模型工具列表中消失。

## 设计要点

- **provider 拥有工具**：名字、描述、schema、实现都在适配器里，hub 不翻译不抽象
- **单一来源**：同一时刻只挂一个 provider，避免两套搜索互相抢调用
- **名字带前缀**：`<provider>_<tool>`，跨来源唯一，切换来源不会让旧记录失效
- **密钥可选**：`keyRequired` 由适配器声明；非必需时缺失即匿名
- **按 agent 屏蔽内置工具**：`ctx.tools.restrict` + guard 兜底，插件卸载自动恢复

## 边界

- 目前一次只有一个来源生效
- 内置网页工具属于 Agent preset，只能屏蔽不能卸载
- 适配器新增需要发布新版本（暂不支持第三方运行时注册）
